“AI co-author” is project attribution. It records substantive creative and
engineering contributions to this repository. It does not assert that an AI

OpenAI, Anthropic, or Moonshot AI sponsors, endorses, or operates this project.

When a commit needs machine-readable attribution, this project uses trailers
such as:

```text
AI-Collaborator: Aheng (Codex by OpenAI)
AI-Collaborator: Awen (Claude by Anthropic)
AI-Collaborator: Ashuo (Kimi Code by Moonshot AI)
```

The project does not invent email identities for AI systems or use GitHub's
`Co-authored-by` trailer for an AI system without an actual account and email.
